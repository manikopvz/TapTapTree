# Complete raster game art

Tap Tap Tree ships a complete WebP art set generated by `scripts/generate-art.py` and committed by CI.

Runtime categories:
- 6 independent parallax background layers
- 7 tree evolution sprites
- apples, Golden Apple and basket props
- grass and rock environment props
- raster particles and glow effects
- upgrade icons
- permanent-skill icons
- achievement badges
- textured UI panels, buttons, slots and progress art

All gameplay-visible artwork is loaded as raster textures. PixiJS Graphics is used only for the invisible tree pointer hit area.
