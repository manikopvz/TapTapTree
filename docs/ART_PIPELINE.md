# Tap Tap Tree raster art pipeline

SVG is prohibited. Runtime art uses PNG/WebP textures through PixiJS Assets/Texture/Sprite. Source art is exported to WebP; particles reuse raster sprites. WorldRenderer contains no procedural visible tree/canopy/apple art; Graphics is permitted only as an invisible pointer hit-area. Asset names are centralized in AssetSystem.

Target folders:
- assets/images/backgrounds
- assets/images/trees
- assets/images/items
- assets/images/icons/upgrades
- assets/images/icons/skills
- assets/images/icons/achievements
- assets/images/fx
- assets/audio/sfx
- assets/audio/music
