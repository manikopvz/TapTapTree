# 🍎 Tap Tap Tree
One tree. Endless apples.

Tap the tree, harvest apples, buy upgrades, build combos and trigger Tree Frenzy.

## Current features
- Responsive desktop/mobile UI
- Tap combo + critical hits
- Tree Frenzy burst mode
- Passive apples per second
- Five upgrade paths
- Local save via localStorage
- Zero dependencies; GitHub Pages ready
